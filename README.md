# Corridor X Connect

CORRIDOR ONE X LANDING PAGE

Build a single-page marketing landing page for Corridor One X, a B2B commodity trade platform that connects verified producers, exporters, and importers directly — with AI matching, autonomous settlement, and escrow-secured payment. Tone: serious, institutional, intelligent. Not a playful startup. Think trade infrastructure with a technical edge.

TYPOGRAPHY

Headlines: Switzer (available free on Fontshare). Use medium/semibold weights, tight letter-spacing.

Body: Svatopluk (available on Google Fonts). Regular weight.

If either font can't be loaded, fall back to a clean humanist grotesque (e.g. Manrope), never a default system serif.

COLOR PALETTE (use these exact hex values)

Primary background: #0A0A0A (near-black)

Raised surfaces / cards: #141414

Elevated surfaces: #1E1E1E

Brand accent (lime): #C4D82E — use scarcely, only for: primary CTAs, the logo mark, verification/active states, key highlights, and the glow in the gradient. Do not flood the page with it. Its power is scarcity.

Accent hover (lighter): #D6E85A

Accent pressed (darker): #9CAD1F

Primary text on dark: #EDEFEA

Secondary text: #C1C8BE

Muted text / captions: #8A9285

Borders / dividers: #3A3F38

LIGHT SECTIONS — IMPORTANT
The page is predominantly dark, but it must NOT be entirely dark. Include at least one, ideally two, full light sections on a near-white background (#EDEFEA or #F4F1EC) with dark text (#0A0A0A), to break the rhythm and add contrast. Good candidates for light treatment: the "Trust & Protection" section and the "Who It's For" section. On light sections, the lime accent stays the same and dark text replaces light text. The alternation between deep-dark and light should feel intentional and premium.

SIGNATURE VISUAL — THE CORRIDOR GLOW
The brand concept is a "corridor of light through a void." Use soft radial/linear gradient glows in the brand lime (#C4D82E) bleeding up from the bottom or center of key dark sections (hero, section dividers, final CTA), fading into the near-black. Subtle, atmospheric — like light down a corridor. Curved faint corridor lines/arcs can frame the hero. Never harsh; always soft-focus and premium. Keep these glows on dark sections only.

GENERAL RULES

Every CTA on the page says "Book a Demo."

Generous spacing, large type, strong hierarchy. Let sections breathe.

Smooth scroll, subtle fade-in-on-scroll animations, and gentle hover states on cards and buttons.

Fully responsive; mobile-first.

Alternate dark and light sections so the page has rhythm — never an unbroken wall of black.

FRAMEWORK
Build this in Next.js (App Router) with React and Tailwind CSS, as this will become the production marketing site and needs SEO, fast load, and server rendering. Use a clean component structure — one component per section — so it's maintainable. Use shadcn/ui or a similar component library for base elements (buttons, accordions, cards). If Next.js introduces significant friction, a Vite + React + Tailwind build is an acceptable fallback — prioritise a working, polished result over the framework choice.
